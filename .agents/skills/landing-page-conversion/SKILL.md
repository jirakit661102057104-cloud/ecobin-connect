# Landing Page Conversion Optimization Skill

## Page structure that converts (default order, adapt to product)
1. **Hero**: one clear value proposition (what it does + who it's for), a single primary CTA above the fold, minimal supporting copy. Avoid a hero that has to explain the product before the value is clear.
2. **Social proof band**: logos/testimonials/usage stats directly under the hero — reduces bounce before the visitor has to think.
3. **Problem → solution**: 2-4 sections mapping a specific user pain to how the product solves it, not a generic feature list.
4. **Feature showcase**: visual (screenshot/demo/3D) paired with a short benefit statement per feature — benefit first, feature second.
5. **Pricing** (if applicable): clear tiers, one visually emphasized "recommended" tier, transparent about what's included — hidden pricing hurts conversion for self-serve SaaS.
6. **FAQ / objection handling**: address the top 4-6 real objections (security, migration effort, pricing concerns) directly.
7. **Final CTA**: restate the value prop, repeat the primary action.

## CTA discipline
- **One primary CTA per section**, consistent wording/color for the primary action throughout the page (don't dilute with 4 different competing CTAs).
- Primary CTA copy states the outcome, not the mechanism: "Start building free" over generic "Submit"/"Click here."
- Secondary CTA (e.g. "Watch demo," "View docs") visually subordinate to the primary.

## Trust & friction reduction
- Show pricing/no-credit-card-required language near signup CTAs if true — uncertainty about cost is a top drop-off cause.
- Testimonials with a real name, role, and company (with photo/logo) convert meaningfully better than unattributed quotes.
- Page load speed is a conversion factor, not just a technical metric — hero image/video must be optimized (see `performance-seo-optimization` skill); a slow hero directly costs conversions.

## Copy principles
- Headlines speak to the visitor's outcome ("Ship your SaaS in weeks"), not the company's internal jargon ("Our proprietary platform").
- Keep body copy scannable: short paragraphs, bolded key phrases, bullet lists over dense paragraphs.

## Anti-patterns to flag
- Hero section requiring scroll to understand what the product does
- More than one visually-competing primary CTA in the same viewport
- Pricing page with vague "Contact us" as the only option for a self-serve-appropriate product
- Heavy unoptimized hero video/image tanking LCP
