# พัฒนาบนเครื่องตัวเอง

โหมดนี้แยกจากเว็บ Vercel ใช้เทส UI และ API บนโน้ตบุ๊ก

## รัน

ดับเบิลคลิก `run.bat` หรือใน PowerShell:

```powershell
cd C:\Users\Lenovo\Downloads\ecobin-connect
.\run.bat
```

- เว็บ: http://localhost:3000/login
- API: http://localhost:8080/health

ปิดหน้าต่างนั้นเพื่อหยุด แล้วรันใหม่เมื่อแก้ `backend.env`

## ไฟล์ config บนเครื่อง (ไม่ขึ้น Git)

- `backend/backend.env` — MySQL, JWT, Google secret, CORS
- `frontend/frontend.env` คัดลอกไป `frontend/.env.local` โดย `run.bat`

`CORS_ORIGIN` ตอนพัฒนาอย่างน้อยต้องมี `http://localhost:3000`

## PowerShell กับไฟล์ .bat

Windows PowerShell ไม่รันไฟล์ในโฟลเดอร์ปัจจุบันถ้าไม่ใส่จุด:

```powershell
.\deploy-cloud-run.bat
.\run.bat
```

ถ้าพิมพ์แค่ `deploy-cloud-run.bat` จะขึ้นว่า term is not recognized

## สิ่งที่ยังอยู่บนเครื่อง vs ของจริง

| งาน | ใช้แบบไหน |
|---|---|
| แก้หน้าเว็บแล้วอยากให้คนอื่นเห็น | push `main` ให้ Vercel build |
| แก้ Go API แล้วอยากให้เว็บจริงใช้ | รัน `.\deploy-cloud-run.bat` |
| ทดลองคนเดียวบนเครื่อง | `.\run.bat` |

ไม่ต้องเปิด Cloudflare Tunnel เมื่อพัฒนาบน localhost
