# พัฒนาบนเครื่องตัวเอง

โหมดนี้แยกจากเว็บ Vercel ใช้เทส UI และ API บนโน้ตบุ๊ก

## รัน

ดับเบิลคลิก `run.bat` หรือใน PowerShell:

```powershell
cd D:\Jirakit_IT04\Project\ecobin-connect
.\run.bat
```

- เว็บ: http://localhost:3000/login
- API: http://localhost:8080/health
- Log backend: `logs/backend.log` (ถ้า API ไม่ขึ้น จะโชว์ท้ายไฟล์นี้ตอน start)

ปิดหน้าต่างนั้นเพื่อหยุด แล้วรันใหม่เมื่อแก้ `backend.env`

## Backend ต่อ MySQL ไม่ได้ (แก้ก่อนอย่างอื่น)

อาการ: ไม่มี `EcoBin API listening` / `run.bat` เตือน Backend NOT healthy / log มี `mysql not ready`

เครื่องนี้ชี้ `MYSQL_DSN` ไป **Cloud SQL public IP** แต่ IP บ้านยังไม่ได้รับอนุญาต (หรือไฟร์วอลล์บล็อก 3306)

### แนะนำทำอันนี้ก่อน: Authorized networks (เร็วสุด)

1. เปิด [Cloud SQL Connections](https://console.cloud.google.com/sql/instances) → instance `ecobin-mysql` → **Connections** → **Networking**
2. ดู IP สาธารณะของเครื่องตอนนี้ (เช่นค้น Google ว่า “what is my ip”)
3. **Add a network** เช่น `Home` = `x.x.x.x/32`
4. Save แล้วรอ ~1 นาที
5. รันใหม่:

```powershell
cd backend
go run .
```

ต้องเห็นประมาณ:

```
connecting to MySQL (...) …
MySQL OK
running migrations…
EcoBin API listening on :8080
```

### ทางเลือกที่เสถียรกว่า: Cloud SQL Auth Proxy

ไม่ต้องเปิด IP สาธารณะถาวร

1. ติดตั้ง [Cloud SQL Auth Proxy](https://cloud.google.com/sql/docs/mysql/connect-auth-proxy)
2. รัน (แก้ PROJECT ให้ตรงโปรเจกต์ GCP):

```powershell
cloud-sql-proxy PROJECT_ID:asia-southeast1:ecobin-mysql --port 3306
```

3. ใน `backend/backend.env` ตั้ง DSN ชี้ local ชั่วคราว:

```env
MYSQL_DSN=root:PASSWORD@tcp(127.0.0.1:3306)/ecobin?parseTime=true&charset=utf8mb4&loc=Local
```

### บังคับให้เว็บ local คุย backend local

ใน `frontend/frontend.env`:

```env
API_PROXY_TARGET=http://127.0.0.1:8080
```

ถ้าเว้นว่างไว้ proxy จะ fallback ไป **Cloud Run** (เลยเห็น API 200 ทั้งที่ `:8080` ยังไม่ขึ้น)

## ไฟล์ config บนเครื่อง (ไม่ขึ้น Git)

- `backend/backend.env` — MySQL, JWT, Google secret, CORS
- `frontend/frontend.env` คัดลอกไป `frontend/.env.local` โดย `run.bat`

`CORS_ORIGIN` ตอนพัฒนาอย่างน้อยต้องมี `http://localhost:3000`

## PowerShell กับไฟล์ .bat

Windows PowerShell ไม่รันไฟล์ในโฟลเดอร์ปัจจุบันถ้าไม่ใส่จุด:

```powershell
.\deploy-cloud-run.bat
.\run.bat
```

ถ้าพิมพ์แค่ `deploy-cloud-run.bat` จะขึ้นว่า term is not recognized

## สิ่งที่ยังอยู่บนเครื่อง vs ของจริง

| งาน | ใช้แบบไหน |
|---|---|
| แก้หน้าเว็บแล้วอยากให้คนอื่นเห็น | push `main` ให้ Vercel build |
| แก้ Go API แล้วอยากให้เว็บจริงใช้ | รัน `.\deploy-cloud-run.bat` |
| ทดลองคนเดียวบนเครื่อง | `.\run.bat` |

ไม่ต้องเปิด Cloudflare Tunnel เมื่อพัฒนาบน localhost
