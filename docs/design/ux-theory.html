Stageใน EcoBin

Defineต้องการบันทึกการคัดแยก + แต้ม + ของรางวัล + รายงาน Admin

03 · Heuristic audit (ย่อ)

Nielsen 10 — เลือกข้อที่ชัดในระบบ

Heuristicหลักฐานใน EcoBinสถานะ
1. Visibility of system status ผล AI + % ความมั่นใจ · สถานะกำลังวิเคราะห์ · แต้มใน Header ผ่าน
2. Match real world คำว่า “แต้ม / แลกรางวัล / จุดทิ้ง / สแกน QR รับของ” ผ่าน
3. User control and freedom ยกเลิกแลก · ถ่ายใหม่ · Guest ออกไป Login ผ่าน
4. Consistency and standards Header: Logo · EcoBin · PCRU · Nav · แต้ม/Avatar ทุกหน้า ผ่าน
5. Error prevention สมาชิกต้องถ่ายจากกล้อง (กันรูปจากเน็ต/แกลเลอรีเพื่อได้แต้ม) ผ่าน
6. Recognition rather than recall เมนูชัด · Filter chips · ประวัติแยกแท็บ ผ่าน
9. Error recovery ข้อความ login ผิด · AI ไม่ผ่านเกณฑ์ → ถ่ายใหม่ ผ่าน
10. Help and documentation คู่มือพลาสติก · Research modal · คู่มือถ่ายรูป ผ่าน

04 · Laws of UX (เลือกใช้)

Fitts · Hick · Miller

Lawการออกแบบ EcoBin
Fitts’s Law ปุ่ม primary เต็มความกว้างบนมือถือ (เข้าสู่ระบบ / ยืนยันบันทึก / ยืนยันแลก)
Hick’s Law Nav Member 4 รายการ · Admin 3 รายการ — ลดตัวเลือกพร้อมกัน
Miller’s Law Dashboard โฟกัส KPI หลัก 4 ใบ + CTA เดียว ไปสแกน — ไม่ยัดงานเกินใน viewport แรก

05 · User Journey (Member)

เส้นทางประสบการณ์หลัก

01 Awareรู้ว่ามีจุดทิ้ง / แคมเปญรีไซเคิล
02 Enterเปิดเว็บ · Login / Guest
03 Scanเปิดกล้อง · AI ≥80%
04 Rewardได้แต้ม · ดู Dashboard
05 Redeemแลกของ · ได้ QR
06 PickupAdmin สแกน QR จ่ายของ

Guest journey สั้นกว่า: สแกนทดลอง → เห็นผล AI → CTA เข้าสู่ระบบเพื่อได้แต้มจริง (ไม่มี Redeem)

06 · User Flows (ในระบบ)

หน้า → หน้า ไม่รวมอารมณ์

Flow A — สมาชิกได้แต้ม
Login → Dashboard → สแกนขยะ → เปิดกล้อง → ถ่าย → AI ≥80% → เลือกจุดทิ้ง → ยืนยัน → แต้มเพิ่ม · แผ่น wireframe 3
Flow B — Guest ทดลอง
Guest → สแกน → (กล้องหรืออัปโหลดได้) → ผลทดลอง → CTA Login · แผ่น 4
Flow C — แลกของ + จ่ายของ
ของรางวัล → Modal ยืนยัน → QR/pickup code → Admin สแกน QR → ยืนยันจ่าย · แผ่น 5–6, 13

07 · Usability Testing tasks

ใช้ในบททดสอบเล่มวิจัย

TaskScenarioสำเร็จเมื่อ
T1 Login เข้าสู่ระบบด้วยบัญชีทดสอบ เห็น Dashboard + แต้มใน Header
T2 สแกนได้แต้ม ถ่ายขวดจากกล้องในแอป แล้วบันทึก ได้แต้ม / รายการปรากฏในประวัติ
T3 แลกรางวัล เลือกรางวัลที่แต้มพอ แล้วยืนยัน ได้ QR หรือรหัสรับของ
T4 Admin QR แอดมินสแกน QR หรือพิมพ์รหัส แล้วจ่ายของ สถานะเป็นจ่ายแล้ว
